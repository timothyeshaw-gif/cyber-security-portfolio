# TryHackMe - SOC Fundamentals

## Overview

This room introduced the purpose, structure and operation of a Security Operations Centre (SOC). It explained how SOC teams monitor security events, investigate potential threats and coordinate responses to cyber security incidents.

- Security monitoring
- Threat detection
- Incident response fundamentals
- SOC operations
- Security event analysis
- Threat intelligence awareness
- Security workflow understanding

## Key Concepts Covered

### Security Operations Centre (SOC)

A SOC is responsible for monitoring, detecting, investigating and responding to cyber threats affecting an organisation.

### Security Monitoring

SOC analysts continuously monitor security tools and systems to identify suspicious activity and security incidents.

### Threat Detection

Threat detection combines alerts, logs, intelligence sources and analyst investigation to identify malicious activity.

### Incident Response

SOC teams play a critical role throughout the incident response lifecycle, from detection and containment through to recovery and lessons learned.

### Threat Intelligence

Threat intelligence provides contextual information about emerging threats, attacker tactics, techniques and procedures (TTPs).
