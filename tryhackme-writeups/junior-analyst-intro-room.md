# TryHackMe - Junior Security Analyst Intro

## Overview

This room introduced the role of a Junior Security Analyst within a Security Operations Centre (SOC). It explored how security analysts monitor networks, investigate alerts, respond to incidents, and support an organisation's overall security posture.

## Skills Demonstrated

- Security monitoring
- Alert triage
- Incident investigation
- Threat detection
- Log analysis
- Security operations
- Incident response fundamentals
- Cyber defence concepts

## Key Areas Covered

### Security Operations Centre (SOC)

Learned how a SOC functions as a centralised team responsible for monitoring, detecting and responding to security threats.

### Responsibilities of a Junior Security Analyst

Developed an understanding of day-to-day analyst tasks including:

- Monitoring alerts
- Investigating suspicious activity
- Reviewing security events
- Escalating incidents
- Maintaining documentation

### Threat Detection

Explored how analysts identify malicious activity through log analysis and alert monitoring.

### Incident Response

Introduced the incident response lifecycle and the role analysts play during security incidents.

## Tools and Technologies

The room introduced technologies commonly used by SOC analysts, including:

- SIEM platforms
- Log management systems
- Security monitoring tools
- Threat intelligence resources

## Key Learning Outcomes

After completing this room I can:

- Describe the role of a Junior Security Analyst
- Explain the purpose of a SOC
- Understand the stages of incident response
- Identify how alerts are monitored and investigated
- Recognise the importance of escalation procedures

## Workplace Application

In a real-world security operations environment, these skills would be applied to:

- Monitor security alerts and events
- Investigate suspicious activity
- Identify potential security incidents
- Escalate incidents according to organisational procedures
- Support incident response and recovery activities

## Reflection

This room provided an overview of how security operations teams function and helped connect many of the concepts I have studied in cyber security. It reinforced the importance of structured investigation processes, accurate documentation and effective communication when responding to security events.
