## Key Learning Points

### Windows Editions and Security Features

I explored the different editions of Windows and the security features available within them. A key takeaway was understanding how Windows Pro includes additional security capabilities such as BitLocker drive encryption, which helps protect data if a device is lost or stolen.

### Windows Desktop and Navigation

The room introduced the main components of the Windows graphical user interface (GUI), including:

- Start Menu
- Taskbar
- Notification Area
- System Settings
- Control Panel

Understanding these features is essential for navigating, configuring and administering Windows systems.

### NTFS File System

I learned about the New Technology File System (NTFS), which is the primary file system used by modern Windows operating systems. The room explained how NTFS supports permissions, access controls and security features that help protect files and folders from unauthorised access.

### User Accounts and Permissions

A significant part of the room focused on user accounts, groups and permissions. I explored the differences between standard users, administrators and built-in accounts, along with how Windows uses groups to control access to resources.

This reinforced the importance of the principle of least privilege, ensuring users only have the permissions required to perform their role.

### User Account Control (UAC)

I gained an understanding of User Account Control (UAC) and its role in preventing unauthorised system changes. UAC acts as an additional security layer by requiring approval before administrative actions can be performed.

### Windows System Utilities

The room also introduced several important Windows administration tools including:

- Control Panel
- System Information
- Local Users and Groups
- Task Manager
- System Variables

These utilities provide visibility into system configuration and are commonly used by IT administrators and cyber security professionals.
