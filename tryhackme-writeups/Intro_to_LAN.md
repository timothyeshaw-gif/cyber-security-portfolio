## Key Learning Points

### Network Topologies

Explored the advantages and disadvantages of common LAN topologies:

- **Star Topology** - Devices connect to a central switch or hub. Highly scalable and the most common topology in modern networks.
- **Bus Topology** - Devices share a single backbone cable. Cost-effective but introduces a single point of failure.
- **Ring Topology** - Devices pass data around a circular path, providing structured communication between devices. 【1-9eaf1d】【2-41d1bf】

### Subnetting

Learned how subnetting:

- Organises large networks into smaller, manageable segments.
- Reduces unnecessary network traffic.
- Improves performance and administration.
- Forms the basis of efficient IP address management. 【2-41d1bf】

### ARP (Address Resolution Protocol)

Developed an understanding of how ARP:

- Resolves IP addresses to MAC addresses.
- Enables devices on a local network to locate each other.
- Supports communication at the Data Link layer of the network. 【2-41d1bf】

### DHCP (Dynamic Host Configuration Protocol)

Learned how DHCP:

- Automatically assigns IP addresses to devices.
- Provides network configuration information.
- Reduces administrative overhead and configuration errors.
- Enables devices to join a network quickly and efficiently. 【2-41d1bf】
