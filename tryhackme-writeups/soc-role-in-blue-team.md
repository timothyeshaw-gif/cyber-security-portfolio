# TryHackMe - SOC Role in Blue Team

## Overview

This room explored the role of a Security Operations Centre (SOC) within a Blue Team environment. It provided an introduction to the responsibilities, processes and technologies used by defenders to detect, investigate and respond to cyber security threats.

## Skills Demonstrated

- Security monitoring
- Threat detection
- Incident response
- Alert investigation
- Security operations
- Defensive security
- Threat intelligence awareness
- Risk-based decision making

## Key Concepts Covered

### Blue Team Responsibilities

Blue Teams are responsible for protecting organisational systems, detecting threats and responding to security incidents.

### Security Monitoring

Continuous monitoring enables analysts to identify suspicious behaviour and investigate potential threats before they impact the organisation.

### Threat Detection

Defenders use alerts, logs and intelligence sources to identify malicious activity occurring within a network or endpoint environment.

### Incident Response

Blue Teams support the identification, containment, eradication and recovery phases of incident response.

### Threat Intelligence

Threat intelligence provides context regarding attacker behaviour, indicators of compromise (IOCs) and emerging threats.

## Tools and Technologies

Common technologies used by Blue Teams include:

- Security Information and Event Management (SIEM)
- Endpoint Detection and Response (EDR)
- Threat Intelligence Platforms
- Security Monitoring Tools
- Log Aggregation Systems
