## Key Learning Points

### System Configuration (MSConfig)

I learned how to use the System Configuration utility to troubleshoot startup issues and access a variety of Windows administrative tools. This provided a useful overview of the built-in utilities available for system management and investigation.

### User Account Control (UAC)

The room explored User Account Control in greater depth, demonstrating how Windows separates standard and administrative privileges to reduce the risk of unauthorised changes. This reinforced the importance of least privilege and privileged access management.

### Computer Management

I was introduced to the Computer Management console and several administration tools, including:

- Task Scheduler
- Event Viewer
- Shared Folders
- Local Users and Groups
- Device Manager
- Disk Management

These tools provide valuable insight into how Windows systems are managed and monitored in both operational and security contexts.

### System Information

Using the System Information utility, I explored hardware, software and operating system data. This demonstrated how important system information is when troubleshooting issues or investigating security incidents.

### Resource Monitor

The Resource Monitor provided visibility into CPU, memory, disk and network activity. Understanding these metrics is useful when diagnosing performance issues, identifying bottlenecks and investigating unusual system behaviour.

### Command Line Utilities

The room reinforced several useful Windows command-line tools including:

- ipconfig
- hostname
- whoami
- systeminfo

These commands provide quick access to system and network information and remain valuable tools for administrators and security professionals.

### Windows Registry

I learned about the Windows Registry and its role as a central database for storing operating system and application settings. The room highlighted both the importance and sensitivity of the registry, as incorrect changes can have a significant impact on system stability and security.

## Why This Matters

Many cyber security activities involve understanding how a system is configured, identifying unusual behaviour and gathering evidence during investigations. The tools covered in this room are commonly used by system administrators, SOC analysts, incident responders and forensic investigators to understand what is happening on a Windows system.

Developing familiarity with these native Windows tools strengthens troubleshooting skills and provides a foundation for more advanced topics such as Active Directory, log analysis, threat hunting and incident response.

## Reflection

This room helped me move beyond viewing Windows simply as an operating system and begin understanding the tools that sit behind day-to-day administration and security operations.

The sections covering Computer Management, Event Viewer and System Information were particularly interesting because they showed how much information Windows records about itself. As someone developing an interest in defensive security, I found it useful to see where this information is stored and how it can be used to understand system activity.

The Windows Registry was another area that stood out. Before completing this room, I understood that the registry existed but had little appreciation of how central it is to the operation of Windows. Learning about its role helped me understand why it is often referenced in both system administration and cyber security investigations.

One of my biggest takeaways was the value of the tools already built into Windows. Rather than relying immediately on third-party software, there is often a wealth of information available through native utilities. Being able to locate and interpret that information is a valuable skill for both troubleshooting and security investigations.

Looking back at my recent studies in networking, vulnerability management and cyber security testing, I can see how this room helps bridge the gap between security theory and the practical reality of managing and protecting systems. Understanding where information is stored, how systems are configured and how activity is monitored will be increasingly important as I progress into Active Directory, system monitoring and incident response.

Overall, this room strengthened my Windows administration knowledge and provided a valuable introduction to the tools commonly used to manage, monitor and investigate Windows environments.
