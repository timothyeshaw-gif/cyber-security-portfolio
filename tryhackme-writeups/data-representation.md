# TryHackMe - Data Representation

## Overview

Today I completed the **Data Representation** room on TryHackMe.

This room explored how computers store, process and represent information. It covered binary, hexadecimal, character encoding and how different types of data, such as text, numbers and colours, are converted into formats that computers can understand.

Although these concepts sit beneath the surface of everyday computing, they form the foundation of many areas of networking, cyber security, digital forensics and software development.

**Room:** Data Representation  
**Platform:** TryHackMe  
**Module:** Pre-Security

---

## Key Learning Points

### Binary

I learned how computers represent information using binary digits (bits), where every value is stored as either a 0 or a 1.

Understanding binary helped explain how computers process instructions, store data and perform calculations using electronic signals.

### Decimal, Binary and Hexadecimal Conversion

The room introduced the relationship between decimal, binary and hexadecimal numbering systems.

I practised converting values between these formats and learned why hexadecimal is frequently used within computing. Hexadecimal provides a more readable way to represent large binary values while maintaining a direct relationship with the underlying data.

### Character Encoding

I explored how computers represent letters, numbers and symbols using character encoding standards.

This helped me understand how text is stored digitally and how different characters are assigned numerical values that computers can process and display.

### Colour Representation

The room also explained how colours are represented digitally using hexadecimal values.

This demonstrated how seemingly complex information can ultimately be reduced to combinations of binary values that computers interpret and display.

---

## Why This Matters

Many areas of cyber security involve working with data at a low level. Binary and hexadecimal notation appear regularly in network analysis, log investigation, memory analysis, malware research, packet inspection and digital forensics.

Understanding how data is represented makes it easier to interpret technical information and understand what systems are actually doing behind the scenes.

## Reflection

At first glance, this room felt less directly related to cyber security than networking, Windows administration or vulnerability management. However, as I worked through the exercises, I began to appreciate how fundamental these concepts are.

One of the biggest lessons for me was that many of the tools and technologies used in cyber security are built on concepts such as binary and hexadecimal. I have already encountered hexadecimal values in networking and security tools, but I previously viewed them as something to memorise rather than something to understand. This room helped bridge that gap.

What I found particularly interesting was seeing how everything ultimately comes back to data. Whether it is a piece of text, an image, a file, an IP address or a log entry, computers are simply storing and processing information in formats they can understand.

As I continue my cyber security studies, I can see how this foundational knowledge will support future learning in areas such as packet analysis, digital forensics, memory investigation and malware analysis. It reinforced the idea that a strong understanding of the fundamentals makes more advanced topics easier to understand later on.

Overall, this room strengthened my appreciation for the underlying technologies that make modern computing possible and highlighted the importance of building solid foundations before moving into more advanced cyber security concepts.
