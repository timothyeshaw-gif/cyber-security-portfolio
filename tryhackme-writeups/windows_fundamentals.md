# Windows Fundamentals

**Platform:** TryHackMe  
**Room:** Windows Fundamentals  
**Status:** Completed

## Objective

This room introduced the fundamental features and functionality of the Microsoft Windows operating system. The aim was to develop an understanding of the Windows environment, system settings, file systems and core administrative tools.

## Topics Covered

- Windows desktop and user interface
- File Explorer and file management
- Windows file systems
- User accounts and permissions
- Control Panel and Settings
- Task Manager
- System Configuration tools
- Windows security features
- Administrative utilities

## Key Learning

Through this room I developed a better understanding of how Windows systems are structured and managed. I gained familiarity with common administrative tools and learned how security settings, user accounts and system utilities contribute to the overall security of a Windows environment.

## Why This Matters

A strong understanding of Windows is important in cyber security because many organisations use Windows-based systems. Security professionals need to understand how these systems operate in order to identify vulnerabilities, investigate incidents and implement appropriate security controls.
