# TryHackMe - What is Networking?

## Overview

This room introduced the fundamental concepts of computer networking and explained how devices communicate across local and global networks. As networking forms the foundation of modern cyber security, understanding how devices identify, locate and communicate with one another is essential before progressing into areas such as vulnerability management, penetration testing and defensive security.

The room explored networks, the Internet, IP addressing, MAC addresses and the use of ICMP through the ping utility. These concepts provide the building blocks for understanding how cyber attacks and defensive controls operate within networked environments.

---

## What I Learned

### What is a Network?

A network consists of two or more connected devices that can communicate and share information. Networks exist at many scales, from small home networks to the Internet itself.

Examples include:

- Home networks
- Corporate networks
- Mobile phone networks
- The Internet

Understanding networks is critical because almost all modern cyber attacks involve some form of network communication.

---

### The Internet

The Internet is a global network made up of many smaller networks connected together.

I learned that:

- The Internet originated from the ARPANET project.
- The World Wide Web (WWW) was invented by Tim Berners-Lee.
- Communication across the Internet relies on standardised protocols and addressing systems.

This helped me understand how information can be transmitted across complex global infrastructures.

---

### IP Addresses

Every device connected to a network requires an Internet Protocol (IP) address.

Key concepts included:

- IP addressing
- IPv4 structure
- Octets
- Device identification on a network

IP addresses allow devices to locate and communicate with one another in a similar way to postal addresses.

---

### MAC Addresses

A MAC (Media Access Control) address is a unique identifier assigned to a network interface.

Unlike IP addresses, which can change depending on the network, MAC addresses are associated with the network hardware itself.

This demonstrated how devices can be identified at different layers of network communication.

---

### ICMP and Ping

The room introduced the Internet Control Message Protocol (ICMP) and the use of the `ping` utility.

Ping can be used to:

- Test connectivity
- Verify network communication
- Confirm whether a device is reachable

This provided a practical demonstration of how network administrators and security professionals diagnose connectivity issues.
