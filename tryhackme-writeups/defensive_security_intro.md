# TryHackMe - Intro to Defensive Security

## Overview

This room introduced the principles of defensive security and provided an overview of how organisations protect systems, users and data from cyber threats. The content focused on the role of Security Operations Centres (SOCs), threat monitoring, incident response and vulnerability management.

Where offensive security seeks to identify and exploit weaknesses, defensive security focuses on detecting threats, reducing risk and maintaining the security and resilience of systems and services.

---

## What I Learned

### Defensive Security

Defensive security encompasses the controls, processes and technologies used to protect information systems against cyber threats.

Key activities include:

- Security monitoring
- Threat detection
- Incident response
- Vulnerability management
- Security awareness training
- Access control and identity management

A key takeaway was that security is not just about preventing attacks but also identifying and responding to them effectively when they occur.

---

### Security Operations Centres (SOCs)

The room introduced the role of a Security Operations Centre (SOC) and the responsibilities of SOC analysts in monitoring and responding to security events.

Typical SOC activities include:

- Monitoring alerts
- Investigating suspicious activity
- Escalating incidents
- Analysing logs
- Supporting incident response

This highlighted how organisations maintain continuous visibility of their environments and respond to emerging threats.

---

### Threat Detection and Monitoring

Effective defensive security relies on monitoring systems for signs of malicious activity.

Examples include:

- Reviewing system and application logs
- Monitoring network traffic
- Investigating unusual user behaviour
- Correlating security alerts

The lesson reinforced the importance of early detection in minimising the impact of cyber attacks.
