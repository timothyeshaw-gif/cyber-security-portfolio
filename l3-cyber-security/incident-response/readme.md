# Incident Response

This section contains examples of cyber security incident response plans and associated response checklists.

The plans have been developed to demonstrate understanding of incident response processes, including:

- Preparation
- Identification
- Containment
- Eradication
- Recovery
- Lessons Learned (PICERL)
